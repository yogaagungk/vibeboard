Kanban boards that talk to your agents

VibeBoard is a self-hostable kanban board for developers working with AI coding agents. Move a card to "In Progress" and VibeBoard spawns your agent automatically.

Built for the agentic workflow

VibeBoard bridges your kanban board and your AI coding agents so they work as a single system.

⚡

Auto-spawn agents

Move a card to "In Progress" and VibeBoard launches Claude Code, OpenCode, or Codex CLI in your project directory — no manual setup needed.

🔄

Bidirectional MCP

Both you (via UI) and your agent (via MCP tools) control the same board in real time. Agents log progress, move cards, and mark tasks complete.

📋

Multiple workspaces

Each workspace is an independent kanban board linked to a project directory. Switch between projects without losing context.

🔒

Self-hosted & private

Your data stays on your machine. SQLite database stored locally, no cloud dependencies, no accounts, no tracking.

🧵

Git worktree isolation

Each agent card runs in its own git worktree on an isolated branch. Merge or create a PR when the work is done.

📊

Live agent log

Every tool call is recorded in a collapsible sidebar. See what your agents are doing, in real time, with full history.

How it works

A short walkthrough of the agent-driven kanban loop.

1

Create a workspace

Link a project directory to a kanban board. VibeBoard detects your git repository and configures worktree support automatically.

2

Add cards with agents

Create cards in any column, assign a title, tags, priority, and an AI agent (Claude Code, OpenCode, or Codex CLI).

3

Move to In Progress

Drag or click to move a card to "In Progress". VibeBoard spawns the assigned agent in your project directory with full context.

4

Agent works autonomously

The agent reads the board state, implements the feature, commits code, and logs progress — all via MCP tools. You can watch in real time.

5

Move to Done

When finished, the agent (or you) moves the card to "Done". Metrics like exit code, duration, and cost are recorded on the card.
