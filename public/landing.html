Features

Everything the agentic workflow needs

VibeBoard bridges your kanban board and AI coding agents so they work as a single system, without duct tape.

⚡

Auto-spawn agents

Move a card to In Progress and VibeBoard launches the assigned agent in your project directory with full card context. No copy-pasting prompts.

🔄

Bidirectional MCP

You and your agent control the same board in real time. Agents call get_board, move_card, add_card_note and more.

🧵

Git worktree isolation

Each agent works in its own git worktree on an isolated branch. Review the diff in the card, then merge or create a PR without leaving the board.

📊

Live run visibility

Stream agent output live, see checkpoint notes posted by the agent, and get exit code, duration, and token cost on every card when it finishes.

🚦

Flow controls

WIP limits per column, card dependencies with blocked_by, concurrency cap with auto-queue, and priority ordering (high runs first).

🗂️

Multiple workspaces

One board per project. Switch instantly, each with its own columns, cards, agents, and git context. Export any workspace as JSON.

🔍

Search and filters

Full-text search across card titles, descriptions, and tags. Filter by tag, priority, agent, and due date — individually or combined.

🔒

Local-first, private

SQLite stored on your machine. No cloud, no account, no tracking. Run it on a trusted network with optional token-based remote access.

📋

Card templates

Save recurring task patterns as templates per workspace — pre-filled agent, model, tags, priority, and custom prompt. Instant card creation.

How it works

The agent-driven kanban loop

From task to shipped feature, VibeBoard orchestrates the whole cycle.

1

Create a workspace

Link a project directory. VibeBoard detects the git repo and can isolate each agent card in its own branch via git worktrees.

2

Add cards with agents

Create a card, write a description, set tags and priority, and assign an AI agent. Or pick a template for recurring tasks.

3

Move to In Progress

Drag or click. VibeBoard spawns the agent in your repo with full card context. A blue pulse appears on the card as it runs.

4

Agent works, board updates

The agent reads board state, implements the task, commits code, and posts checkpoints via MCP. You watch it live in the Activity tab.

5

Review, merge, and ship

Open the card's diff view, merge the branch or create a PR — all from inside VibeBoard. Card moves to Done with full run metrics recorded.

Quick start

Up and running in 30 seconds

No install required. One command opens the board, the MCP Setup dialog connects your agents.

Terminal
# Run without installing
$ npx @zanuartri/vibeboard
 
VibeBoard v0.3.0
HTTP http://localhost:7341
MCP stdio transport ready
 
# Or install globally
$ npm install -g @zanuartri/vibeboard
$ vibeboard
 
# Connect Claude Code (one-time)
$ claude mcp add -s user vibeboard -- node /path/to/mcp-server/index.js
MCP server "vibeboard" added

Start shipping with your agents

Self-hosted, open source, and ready in one command. No cloud, no account.
